# Frogy v16.8 Quest Test Plan

1. Stand upright in lobby: move using relaxed short forward/sideways arm strokes. Check there is no repeated back-and-forth camera rocking after returning the hands.
2. Stand near a tree/bench: lean your real head toward it WITHOUT swinging. The entire world should not bounce or teleport backward. Swing away; you should be able to leave.
3. Move deliberately toward a solid structure: it should block locomotion, and allow smooth sliding along its edge; avoid walking through physical/real-world boundaries.
4. Jump with A; ensure pushing hands downward doesn't unintentionally make you hop repeatedly while crouching.
5. Repeat as the Mega Frog: should feel a little stronger, never wildly uncontrollable.
6. Create private room: Tadpole must NOT appear automatically. Enter code NPC to spawn it. During round it should gently sway/wiggle but not chase or cause lag.
7. Check X menu → Settings → Camera Lab. Try POV and Follow, record 5 seconds MIC OFF; then try MIC ON with permission and save. Camera and audio remain beta on Quest.
8. In a separate browser visit Frogy homepage; Players Online should increase when a VR player enters and joins a room, decrease when they exit, and never include Tadpole or someone merely browsing the site.
9. Check sword pickup, blaster aim, medkits, map voting, multiplayer, and quests as regressions.

If movement still jitters, record a Quest clip showing hands, environment, and the timing of the arm stroke. Do NOT use the headset near real-world hazards.
