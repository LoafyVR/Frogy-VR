# Frogy v15.0 release notes

- Added server-saved, validated custom frog names via a new two-row NAME tab and QWERTY keyboard.
- Changed survivor health to 175 and Mega Frog health to 520; buffed monster-target blaster and knife hits and added shot-hit feedback. Health stays hidden from other players.
- Added up to 45 seconds of survival after a survivor loses an arm, with server-authoritative expiry.
- Added monster-only lighter gravity, longer travel, and automatic hops on strong hand movement without A.
- Repositioned and enlarged Lucky Lily, expanded its trigger target, added a POND-menu spin shortcut, and added funny bad free-play outcomes.
- Preserved all previous features including private solo NPC test, public matchmaking, codes, voice prototype, wall stick, frog colors, cosmetics, tools, and maps.
- Includes v15 targeted tests and prior regression tests. Meta Quest hardware behavior remains unverified.
