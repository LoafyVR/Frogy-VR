# Frogy v8 headset playtest checklist

- [ ] Exactly two hands at all times, and both stay at controller height
- [ ] Press left hand down and pull backward: move forward without jitter
- [ ] Repeat with right hand; no sudden sideways movement or teleport
- [ ] Floor contact releases reliably on lifting each hand
- [ ] Wall pushes behave like floor pushes without hand vibration
- [ ] Run and press right A: keep momentum during jump
- [ ] Tap left X: menu opens and stays open; tap X again to close
- [ ] All menu tabs visible; shop and Settings text don't overlap
- [ ] First-join three-step tutorial loads; HELP opens it again
- [ ] With menu closed, physically point at lobby vote board and trigger vote
- [ ] New jump SFX plays clearly without being piercing
- [ ] Lobby music is quiet and pauses between songs; Settings Music Level works
- [ ] Both players see each other's bodies and hands in the same room

If movement feels broken, send headset footage showing the head, both arms, and the place where a paw touches the floor. Note the headset model, browser update, and whether standing or crouching.
