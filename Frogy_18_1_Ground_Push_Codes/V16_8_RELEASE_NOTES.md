# Frogy v16.8 Release Notes

- v16.8.0 is built from v16.7; full game with Camera Lab and microphone included.
- Fixed collision-driven XR headset repositioning jitter that could rock the view when physically leaning into cover.
- Limited arm-stroke acceleration; maintained natural standing pushes, trigger-assisted climbing, A jump and modest monster speed advantage.
- Reduced local paw size for headset clarity.
- Practice Tadpole stays optional and only gently sways/wiggles in place during private-room rounds. It does not chase players.
- New real-time Players Online counter on the actual Enter VR launch screen, using `/api/online` and an immersive-session heartbeat. Bots and site visitors aren't counted.
- Camera Lab remains in X → Settings with optional microphone recording; downloading recordings is browser-dependent.
- See test results. Real Quest playtest still required.
