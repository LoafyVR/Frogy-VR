# Quest 17.1 test checklist

Use a separate Render service first. Do not replace the production build until this feels good.

1. **No air pushing:** Jump with A on flat terrain, wave both hands horizontally at waist height. No extra propulsion should occur.
2. **Ground plant:** While standing, lower a controller toward the floor, then push it backward 1–3 cm; you should move forward instead of staying still.
3. **Return stroke:** Reset the hand horizontally at the same height after a push; this must not fling you backward.
4. **Hand jump:** Plant a hand and push straight downward to make a small hop; A should still jump higher.
5. **Real walls:** Jump near a tree and deliberately touch it with a controller. Only actual contact, not a near miss or a fast pass-through, should push or cling.
6. **Fast movement:** Try short, repeated pushes and Swift Legs; check for clipping into nearby walls.
7. **Menu midair:** Open the X menu while jumping; you should keep falling/moving, but menu hands shouldn't push.
8. **Tongue:** Confirm max ~21 m, shared 7-second cooldown.

If it still jerks backward or pushes off air, please record the moment and note whether it happened while A jumping, grappling, standing, or wall-clinging.
