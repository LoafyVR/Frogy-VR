# Quest movement A/B playtest
1. Stand normally, do a tiny 1–3cm forward hand stroke: it should produce a small movement, not a big kick. Repeat sideways.
2. Perform a full-length push: should feel like v15.4, not the v16.9 stopped/braked motion.
3. Push down near the virtual floor without pressing A; then jump using A.
4. Swing hands in the air and compare with v15.4 (this rollback restores its behavior).
5. Walk into a tree/structure: v15.4 let the frog torso pass through props, so check if that freedom feels better or if we need an optional collision compromise.
6. Fire a tongue using B or Y and verify the shared 7-second cooldown.
7. Verify sword pickup, medkit, Players Online and Camera Lab menu still work.

Report especially whether *tiny strokes*, *large strokes*, and *wall interactions* feel better or worse.
