# Frogy v13.0 — Quest Playtest Checklist

Confirm **v13.0** in the VR menu (if not, check Render commit/Root Directory and close/reopen the Quest tab).

- [ ] Paws follow both physical controllers. No double or sinking hands.
- [ ] Alternate arm pushes in the lobby without crouching, sticking to the floor or unexpectedly losing momentum; try walls and trees.
- [ ] Right A jumps and keeps travel speed; the body doesn't snag on walls while paws can push off them.
- [ ] Right B tongue hits solid targets including floor, trees, walls and parkour pads, but not empty sky; reattach/release works.
- [ ] Every parkour pad can be landed on; seven pad tops rise from 0.6 m to 3.28 m.
- [ ] Left X toggles VR menu; ROOM PC → CREATE shows a 5-character code; a friend in another headset can JOIN using that code, and both see each other. A wrong code produces a visible error.
- [ ] CODES → FREE or FROG redeems once on an eligible profile and shows a receipt; second attempt is rejected.
- [ ] DRESS UP → key **907** → APPLY shows a success message; own body and mirror change and friend sees the new color. Re-enter the lobby and verify it persists. Try 000 and 999.
- [ ] A brand-new account receives 500 Crickets + 1,000 Dabloons, and existing accounts don't reset.
- [ ] Frame rate and turning remain comfortable; flag any new clipping or controller glitches.

For a failure, send the Quest model, the v13.0 version shown, a short headset clip, and whether a friend sees the same problem.
