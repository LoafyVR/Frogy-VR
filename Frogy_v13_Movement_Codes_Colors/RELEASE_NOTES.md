# FROGY v13.0 Release Notes

**Based on:** v12.0 — Paws, Climbing & Dancing Mirror  
**Target:** existing Render/WebXR Quest Browser deployment

- Torso no longer blocks movement when touching scenery. Hand push-off is easier; floor/parkour landings and collision probes remain.
- Grapple reaches up to 38 m and attaches to valid solid surfaces, not air.
- Parkour pads are higher and share one collider definition with rendered shapes.
- Private room CREATE and JOIN now receive success/error receipts for reliable VR feedback.
- Promo code input is retained until successful server response; award confirmation visible.
- VR DRESS UP supports a true 0–9 RGB numeric keypad, APPLY confirmation, swatch preview, server validation, multiplayer replication, and saved color across reconnects.
- New players start with 500 Crickets and 1,000 Dabloons, existing profiles remain unchanged.
- 28 automated test suites passed. **No physical Quest test performed**.
